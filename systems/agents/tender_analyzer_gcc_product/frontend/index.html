API Reference

Base URL: http://localhost:8000  |  Auth: X-API-Key header

Analyze a Tender (Text)

curl -X POST http://localhost:8000/api/v1/tenders/analyze \ -H "X-API-Key: YOUR_API_KEY" \ -H "Content-Type: application/json" \ -d '{ "id": "tender-001", "title": "Smart City IoT Infrastructure", "description": "The Dubai Municipality seeks...", "issuer": "Dubai Municipality", "country": "UAE", "sector": "IT" }'

Analyze a PDF

curl -X POST http://localhost:8000/api/v1/tenders/analyze-file \ -H "X-API-Key: YOUR_API_KEY" \ -F "file=@tender.pdf" \ -F "country=UAE" \ -F "sector=Construction"

Get Analysis History

curl http://localhost:8000/api/v1/tenders/history \ -H "X-API-Key: YOUR_API_KEY"

Account Info

curl http://localhost:8000/api/v1/account/me \ -H "X-API-Key: YOUR_API_KEY"

Response Schema

{ "id": "tender-001", "analysis": { "summary": "...", "key_requirements": ["..."], "score": 78, "recommended_action": "pursue", "risk_level": "low", "confidence_score": 0.87, "reasoning": "..." }, "credits_remaining": 49 }
