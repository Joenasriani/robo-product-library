# Support Scope

Support for **GCC Hotel Concierge Protocol** is inquiry-based and delivered by the RoboMarket solutions team.

## Included
- One onboarding handoff call after package delivery
- Guidance on adapting policy YAML files to venue policy
- Clarification of acceptance criteria and escalation behavior

## Not included
- Custom navigation stack implementation
- Hardware procurement or robot firmware support
- 24/7 incident response operations
