# Setup Guide

This setup applies to **GCC Hotel Concierge Protocol**.

1. Import this product folder into your robot behavior workspace.
2. Configure country overlays in `core/country_overlays.yaml` for the deployment country.
3. Enable only the role/state files required by the venue's operating policy.
4. Connect escalation hooks to a staffed human operator channel before pilot use.
5. Run `tests/acceptance_criteria.yaml` checks and the QA checklist before go-live.
