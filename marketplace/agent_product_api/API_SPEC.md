Agent Product API Plan

Purpose:
Serve AI agent products separately from protocol products.

Endpoints:
1. GET /api/v1/agent-products
2. GET /api/v1/agent-products/{slug}
3. POST /api/v1/agent-products/inquiry
4. POST /api/v1/admin/agent-products/approve
5. POST /api/v1/admin/agent-products/deliver

Phase 1:
- inquiry + manual fulfillment

Phase 2:
- paid gated delivery
