# Delivery Scope

## Included in base service

- Browser-based customer-specific simulation package
- Facility zones and obstacle layout based on buyer input
- Robot or machine model configuration based on buyer-provided specifications
- Mission flow configuration
- Interactive map controls
- Rule-based exception scenario prototype
- Sample missions and walkthrough scenarios
- Exportable event log sample
- Technical feasibility note for optional live integration

## Buyer inputs required

- Facility map, sketch, CAD export, or rough zone description
- Machine model names and basic specifications
- Payload limits and speed assumptions
- Required task flows
- Exception scenarios to demonstrate
- Preferred branding and presentation goal
- API or telemetry documentation if integration feasibility is requested

## Out of scope unless separately quoted

- Live production machine operation
- On-site deployment
- Certified industrial compliance approval
- Custom backend infrastructure
- User account system
- Database persistence beyond agreed demo outputs
- Vendor-specific API bridge
- ROS 2, Open-RMF, Nav2, PLC, ERP, WMS, or MES integration

## Acceptance standard

The service is accepted when the agreed customer-specific simulation opens in a browser, demonstrates the scoped robot/facility workflow, shows configured mission and exception scenarios, and includes the agreed feasibility notes.
