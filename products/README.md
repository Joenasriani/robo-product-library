# Products

This folder contains ONLY real, deliverable SKUs.

## Structure

- `protocols/` — sellable protocol products, each with `manifest.yaml`, `RULES.yaml`, `README.md`, and either a `bundle.zip` or documented delivery manifest
- `downloadables/` — staged downloadable customer bundles
- `ai/` — sellable AI product packages
- `catalog.yaml` — canonical product inventory for sellable products only
- `schema/product_schema.yaml` — minimum product standard
- `LISTING_READINESS.md` — listing-readiness rules for future RoboMarket.ae marketplace review
- `PRODUCT_LISTING_TABLE.md` — professional buyer/integrator-facing product table

## Professional Product Table

Use [`PRODUCT_LISTING_TABLE.md`](./PRODUCT_LISTING_TABLE.md) as the current human-readable product overview for future marketplace listing review.

The table is intentionally listing-focused. It does not claim payment checkout, automated download fulfillment, certified safety approval, or live robot deployment.
