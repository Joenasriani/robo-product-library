# RoboSafeOS Limitations

RoboSafeOS is a protocol and documentation package. It is not a certified robot controller, safety-certified runtime, regulatory approval, or replacement for site engineering.

## Explicit limits

- No live robot control is included.
- No ROS2, Nav2, Isaac Sim, AirSim, IR-SIM, BIM, CAD, VDA 5050, or fleet-manager integration is included in this version.
- No compliance certification is claimed.
- No site approval is implied.
- No insurance, municipal, civil defense, medical, or legal approval is included.
- The browser demo is explanatory and does not simulate physics, sensor uncertainty, emergency braking, crowd dynamics, hardware faults, or network failures.

## Required buyer responsibility

The buyer, facility operator, robot vendor, and qualified integrator must review all site-specific constraints before any physical deployment.

## Commercial status

RoboSafeOS is currently inquiry-only. Pricing must not be invented inside repository files. Commercial pricing must be added only after a verified pricing policy exists.
