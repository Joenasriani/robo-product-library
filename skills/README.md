# Skills

Reusable skill modules used across agents and AI product workflows.

## Skill Categories

- [`core/`](./core/) — foundational prompting patterns
- [`control/`](./control/) — constraints, validation loops, output control
- [`agent/`](./agent/) — multi-step planning and tool-use behaviors
- [`rag/`](./rag/) — retrieval and context-injection techniques
- [`llmops/`](./llmops/) — evaluation, observability, prompt versioning
- [`orchestration/`](./orchestration/) — model-routing and orchestration patterns
- [`execution/`](./execution/) — execution adapters (API, file, browser)
- [`business/`](./business/) — business task templates (analysis, writing, outreach)

Each markdown file is a standalone reusable capability spec.
