# robo-agent-task-decomposition

Category: agent
Purpose: Break a complex task into sub-tasks.

## What it does
- organizes work
- reduces mistakes
- allows modular execution

## Pattern
Decompose the task into:
1. inputs needed
2. analysis step
3. transformation step
4. validation step
5. final output

## Use in
- tender analysis
- outreach generation
- protocol building
- report generation
