# robo-prompt-meta-prompting

Category: core
Purpose: Use an LLM to improve or generate another prompt.

## What it does
- turns rough goals into sharper prompts
- useful for standardizing prompt libraries
- supports agent spec generation

## Use when
- converting messy ideas into structured prompts
- refining system prompts
- preparing reusable internal skills

## Pattern
You are a prompt architect.
Given the task below, generate a production-grade prompt with:
- role
- context
- task
- output format
- constraints
- failure prevention

Task:
<insert task>

## Outputs
- reusable prompt template
- prompt variants for different models
