# robo-prompt-chain-of-thought

Category: core
Purpose: Encourage stepwise reasoning for difficult tasks.

## What it does
- improves complex reasoning
- helps decomposition
- supports scoring and classification

## Use when
- evaluating tenders
- ranking options
- comparing alternatives
- detecting risks

## Safer application
Prefer internal reasoning and concise final outputs.
If exposing output, request:
- key factors
- short rationale
- final answer

## Lightweight pattern
Think through:
1. key facts
2. constraints
3. tradeoffs
4. final recommendation

Return:
- concise reasoning
- final result
